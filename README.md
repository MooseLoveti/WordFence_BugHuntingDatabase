# WordFence Bug Hunting Database

## 概要
- 公開された脆弱性におけるそれぞれの「タイトル」「アクティブインストール数」「報奨金見積り」を取得＆計算し、表示。
- 作った理由: 自身のコーディング力を上げたかったから。また、自身がバグハントを行う際、狙い目のプラグインを探すとき便利だと思ったから。

## 仕組み
- `/services/api.py` で Wordfence の脆弱性一覧を取得し、直近7日以内のものを抽出。
- 各プラグインのスラッグから WordPress のプラグイン情報 API を叩き、インストール数などを付与。
- 件数が多いため読み込みが非常に遅いのが難点。直近7日ならギリギリ待てるが、それ以上は厳しい。

## 既知の課題
- 外部 API 依存でレスポンスが遅い。
- 期間が長いとタイムアウト・待ち時間が大きくなる。

## セットアップ
1. 依存ライブラリ: `pip install -r requirements.txt`
2. 実行: `python app.py`（デフォルトで debug=True）
3. ブラウザで `http://127.0.0.1:5000/` を開く。

## ディレクトリ
- `app.py` : Flask エントリーポイント。
- `services/` : API 呼び出しロジック。
- `templates/` : HTML テンプレート。
- `static/` : 静的ファイル。
- `calculate` : 報奨金計算
